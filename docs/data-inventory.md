# 数据清单

Yew Harness 在用户电脑和 iPhone 上保存的数据。Yew Harness 不把这些数据发给榫卯 Tenon AI；发给模型服务商的内容见「关于 Yew」里的隐私政策。新增保存项时先改这份清单和隐私政策，再合入。

数据目录默认是 `~/.yew`，可用 `YEW_HOME` 指定，权限为只有当前用户可读写。

| 数据 | 存放位置 | 来源 | 用途 | 保存期限 | 删除方式 |
| --- | --- | --- | --- | --- | --- |
| 团队、会话设置（名称、职责说明、工作区路径、附加目录及读写权限、会话级沙箱放行域名、模型、权限规则、收信方式和发信额度、任务清单、开它的会话、任务结果、你介入的次数、已发信数） | `yew.db` 的 `groups`、`sessions` 表 | 用户在界面里填写；任务清单、任务结果由会话写入；介入次数和已发信数由 Yew Harness 统计 | 运行会话；任务结果和介入次数留作评测数据 | 直到用户删除 | 在设置的「数据管理」里删除所有归档会话（先归档要删的会话）；删除数据目录 |
| 会话记录（用户消息、模型回复、工具调用与结果、审批与提问、排队消息） | `yew.db` 的 `messages`、`tool_calls`、`approvals`、`queued_messages` 表，以及全文索引 `message_search` | 用户、模型服务商、工具执行结果 | 显示记录、发给模型作上下文、搜索 | 直到用户删除 | 删除归档会话时一并删除，包括全文索引；删除数据目录 |
| 输入框里没发出去的文字（每个会话一份，首页一份；只有文字，不含选好还没发的附件） | `yew.db` 的 `unsent` 表 | 用户在网页界面或 Mac 应用的输入框里打的字 | 页面关掉或离开后再打开时，把没发出去的文字放回输入框 | 直到发出或清空；会话的那一份最长到会话被删除 | 发出消息或清空输入框时删除；删除归档会话时一并删除；删除数据目录 |
| 消息附件（随消息附带的图片、PDF、文本文件的元信息与原始文件） | `yew.db` 的 `attachments` 表；文件在数据目录的 `attachments/<会话>/<附件>/` | 用户在网页或手机端上传、粘贴、拖入的文件 | 在界面和手机端显示附件；按所选模型的能力发给模型服务商（不支持看图的模型降级为文件说明） | 直到用户删除；未发出的孤儿附件 24 小时后启动时清理 | 回溯消息时删除对应附件文件；删除归档会话时一并删除；删除数据目录 |
| 信件（发信方、收信会话、类型、摘要、正文、状态、转发链、所属的定时任务、来自主对话的源消息编号） | `yew.db` 的 `letters` 表 | 会话、`yew send`、用户在审批中心做的决定、定时任务 | 在会话之间传话；审批中心的信件列表；自动授权时溯源主对话本人原话 | 直到用户删除 | 删除归档会话时，寄给它的信一并删除，它寄出的信保留（不再指向它）；删除数据目录 |
| 决定卡和决定（要定什么、选项、期限、涉及的会话、能否撤回、你的选择和备注） | `yew.db` 的 `cards` 表 | 主对话写卡片；用户在审批中心做决定 | 审批中心；会话查验决定 | 直到用户删除 | 同会话记录 |
| 定时任务（名称、时间、寄给哪个会话、执行方式：寄信或新开任务会话、完成后是否自动归档、信的内容、运行时的授权方式、错过时补跑或跳过、开关、下次运行时间、上次运行的时间、结果和任务会话编号） | `yew.db` 的 `schedules` 表 | 用户在「定时任务」页面填写，或主对话经你授权建立；运行结果由 Yew Harness 记下 | 按时给会话寄信或新开独立任务会话 | 直到用户删除 | 在「定时任务」页面删除；删除归档会话时，寄给它的定时任务一并删除；删除数据目录 |
| 审批记录文件 | 用户在设置里指定的 Markdown 文件 | 用户在审批中心做的决定 | 同步到用户自己的文档 | 由用户管理 | 在设置里清空路径后不再写入；文件由用户自己删除 |
| 会话事件 | `yew.db` 的 `session_events` 表 | 会话记录的变化 | 界面断线后补发 | 7 天，`yew serve` 启动时清理 | 自动 |
| 系统提示词快照（环境信息、说明文件内容） | `yew.db` 的 `sessions.context` | 本机环境和用户的说明文件 | 让提示词在多轮之间保持不变 | 直到会话压缩上下文或被删除 | 同会话记录 |
| 用量与费用统计（每个会话的累计，以及每个会话每天的 token 数和费用） | `yew.db` 的 `sessions` 表和 `usage_daily` 表 | 模型服务商返回的 token 数和模型目录里的价格 | 显示用量和费用；按每日费用上限提醒和停下会话 | 直到用户删除 | 同会话记录 |
| 运行日志（启动、出错和连接中继的记录，带会话 id，不含对话内容） | 数据目录的 `logs/serve.log` | 用 `yew service install` 设了开机启动后，`yew serve` 的输出 | 排查问题 | 直到用户删除 | 删除这个文件；删除数据目录 |
| 设置（主题、语言、界面里的 Yew 显示与否、开场自动进入还是点击进入、默认模型、默认权限规则、主对话、审批记录文件的路径，全部会话的每日费用上限，记忆目录的路径，会话读不到的目录的路径，沙箱全局放行域名列表，自动授权是否溯源主对话本人原话，系统沙箱里能否用 SSH 和凭据文件，是否每天检查新版本，保存的工作区：名称和文件夹路径，以及手机访问的开关和中继地址；还有被你停下的会话和停在每日费用上限的会话的编号，重启后据此保持原样） | `yew.db` 的 `settings` 表 | 用户 | 界面和新会话的默认值 | 直到用户修改 | 在设置里修改；删除数据目录 |
| 自定义服务商（名称、接口地址、模型参数） | `yew.db` 的 `providers` 表 | 用户 | 调用这些服务商 | 直到用户删除 | 在设置里删除服务商 |
| 产物（名称、类型、版本号、大小、时间，以及每个版本的文件） | `yew.db` 的 `artifacts`、`artifact_versions` 表；文件在数据目录的 `artifacts/<会话>/<产物>/` | 会话用 save_artifact 保存 | 在界面和手机上看会话做出来的东西 | 直到用户删除 | 在「产物」页面删除；删除归档会话时一并删除；删除数据目录 |
| 搜索服务的密钥 | 系统钥匙串（`search-bocha` 等） | 用户用 `yew key set` 保存 | 会话联网搜索 | 直到用户删除 | `yew key delete` |
| MCP 服务的配置（启动命令或网址、环境变量、请求头） | 数据目录的 `mcp.json`，用户自己写的文件 | 用户 | 连接 MCP 服务 | 直到用户修改 | 编辑或删除这个文件 |
| hooks（在会话的哪些时候跑什么命令、匹配哪些工具） | 数据目录的 `hooks.json`，用户自己写的文件 | 用户 | 在会话开始、发消息时、工具调用前后和会话停下前跑用户自己的命令 | 直到用户修改 | 编辑或删除这个文件 |
| MCP 服务的登录（访问令牌、刷新令牌、Yew Harness 注册的客户端） | 系统钥匙串，服务名下的 `mcp` 一组 | 你在「MCP 服务」里点「登录」，在浏览器里登录对方 | 让会话以你的身份调用这个服务 | 直到你退出登录或删掉这个服务 | 「MCP 服务」里点「退出登录」；服务提供撤销地址时，Yew Harness 先请它作废令牌 |
| 自带的两个 MCP 服务的程序文件（不含个人数据） | 数据目录的 `mcp-builtin` 文件夹 | 第一次使用时按随 Yew Harness 发布的锁文件从 npm 安装 | 运行浏览器和电脑操控 | 直到用户删除；Yew Harness 更新后会重装 | 删除这个文件夹 |
| 常用服务里在本机运行的程序文件（Gitee、Notion、Sentry，不含个人数据） | 数据目录的 `mcp-presets` 文件夹，每个服务一个 | 第一次使用时按随 Yew Harness 发布的锁文件从 npm 安装 | 运行这几个 MCP 服务 | 直到用户删除；Yew Harness 更新后会重装 | 删除这个文件夹，下次使用时重装 |
| 系统沙箱里命令的缓存（npm、pip、Go 等下载的包，不含个人数据） | macOS 的 `~/Library/Caches/yew-sandbox`，Linux 的 `~/.cache/yew-sandbox` | 系统沙箱打开时，会话的命令和 MCP 服务器装包、构建 | 让沙箱里的命令不用你自己的缓存 | 直到用户删除 | 删除这个文件夹 |
| 自带浏览器的资料（在那个窗口里登录过的网站的 Cookie、缓存和历史；只在设置里选了「单独的窗口」时有，默认用你自己的 Chrome，这些留在 Chrome 里） | 数据目录的 `browser` 文件夹 | 用户在自带浏览器里的操作，和会话经浏览器工具的操作 | 让登录状态保持 | 直到用户删除 | 删除这个文件夹；在「MCP 服务」里停用浏览器 |
| Mac 应用的网页数据（登录 Yew Harness 的 Cookie、界面文件的缓存、界面的几项本地设置，不含会话内容）和窗口的位置、大小 | `~/Library/WebKit/cn.tenonai.apps.yew.desktop`、`~/Library/Caches/cn.tenonai.apps.yew.desktop`、`~/Library/HTTPStorages/cn.tenonai.apps.yew.desktop.binarycookies`、`~/Library/Preferences/cn.tenonai.apps.yew.desktop.plist`（macOS 的 WebKit 和系统替应用存的） | 用 `yew app install` 装的 Mac 应用打开界面 | 窗口下次打开时仍是登录状态、回到原来的位置 | 登录 Cookie 30 天不用就失效；其余直到删除 | 退出应用后删除这几处；`yew app uninstall` 只删应用本身 |
| 回溯后留下的占位 | `yew.db` 的会话记录 | 你在界面上回溯 | 回溯时，之后的消息、回复和工具调用的内容、为它们发起的审批、搜索索引和这个会话的事件记录都删掉（删掉的内容在文件里清零），只留不含内容的一行，让序号和引用不断 | 随会话 | 删除会话 |
| 截屏和网页内容（会话用浏览器或电脑操控工具时） | 作为工具结果记在会话记录里，并发给会话所用的模型服务商 | 自带的浏览器和电脑操控服务 | 让模型看到页面和屏幕 | 随会话记录 | 删除会话；停用这两个服务 |
| 登录令牌 | `yew.db` 的 `auth_tokens` 表，只存 SHA-256 哈希 | `yew serve`、`yew open` 生成 | 浏览器登录 | 一次性令牌 10 分钟；浏览器令牌 30 天，使用时顺延 | 过期自动清理；删除数据目录 |
| 幂等记录 | `yew.db` 的 `idempotency_keys` 表 | 界面的创建请求 | 防止重复创建 | 24 小时 | 自动 |
| 超长的命令输出 | `tmp/<会话>/output/*.log` | Shell 工具 | 让模型读取被截断的输出 | 直到用户删除 | 设置的「数据管理」里清理（正在干活的会话的不删），或删除数据目录下的 `tmp` |
| 服务运行信息（端口、进程号） | `serve.json` | `yew serve` | `yew open` 找到正在运行的服务 | 服务运行期间 | 服务停止时删除 |
| 模型服务商的 API Key | 系统钥匙串，服务名 `cn.tenonai.yew` | 用户（`yew key set` 或设置界面） | 调用模型服务商 | 直到用户删除 | 在设置里删除，或运行 `yew key delete <服务商>` |
| 配对的手机（名称、公钥、配对时间、最近连接时间，Apple 给这台手机的推送令牌，是否给它发通知） | `yew.db` 的 `devices` 表 | 手机扫码配对；推送令牌由手机经加密通道交来 | 只让配对过的手机经中继连进来；给它发通知（内容为这台手机加密，中继和 Apple 只经手令牌和密文） | 直到用户移除 | 在设置的「手机访问」里移除，或在 iPhone 上断开配对；删除数据目录 |
| 检查新版本的结果（npm 上最新的版本号和检查的时间） | `yew.db` 的 `settings` 表 | 用 npm 全局安装时，Yew Harness 每天向你的 npm 所用的源查一次（可在「关于」里关掉；从源码运行时不查） | 关于页和 Yew 的气泡说有新版本 | 直到下一次检查 | 删除数据目录 |
| 安卓应用检查新版本的开关和结果（Gitee 上最新发布的版本号和检查的时间） | 安卓应用自己的设置（`updates`） | 安卓应用每天向 Gitee 查一次（可在「关于」里关掉） | 关于页给新版本的下载链接 | 直到下一次检查 | 在「关于」里关掉；卸载应用 |
| 配对码 | `yew.db` 的 `settings` 表，只存 SHA-256 哈希 | 「添加手机」或 `yew remote pair` | 手机首次配对 | 用过一次或 5 分钟后失效 | 自动 |
| 中继的连接日志（时间、IP 地址、方法、主机名、路径和状态；路径里有电脑的标识，是它公钥的哈希；不含请求头、查询串和内容） | 榫卯运行的中继服务器 `/var/log/caddy/access.log`，不在用户设备上 | 电脑和手机连接默认中继时，反向代理记下 | 网络安全（《网络安全法》要求留存不少于六个月） | 184 天，到期自动删除 | 自动；用自己部署的中继就不经过这台服务器 |
| 电脑的远程访问密钥（Noise 密钥、签名密钥） | 系统钥匙串，服务名 `cn.tenonai.yew`，名称以 `remote:` 开头 | 第一次打开手机访问时生成 | 和手机端到端加密；向中继证明是这台电脑 | 一直保留，换密钥后已配对的手机要重新配对 | 在「钥匙串访问」里删除 |
| iPhone 上的配对信息（电脑的 id、公钥、名称、中继地址，这台手机在电脑上的 id）和手机自己的密钥 | iOS 钥匙串，服务名 `cn.tenonai.apps.yew.remote`，只存在这台设备上、不同步 | 扫码配对 | 经中继连接电脑 | 直到断开配对 | 在 iPhone 上的设置里断开配对 |
